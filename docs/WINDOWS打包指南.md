# BOSS 直聘管理工具 - Windows 打包指南

## 一、打包步骤

### 方法 1：使用自动打包脚本（推荐）

1. **准备环境**
   - 确保已安装 Python 3.8 或更高版本
   - 打开 Windows 命令提示符（CMD）或 PowerShell

2. **进入项目目录**
   ```cmd
   cd code
   ```

3. **运行打包脚本**
   ```cmd
   build.bat
   ```

4. **等待打包完成**
   - 脚本会自动安装依赖
   - 清理旧文件
   - 执行打包（可能需要 2-5 分钟）
   - 完成后会显示成功消息

5. **获取可执行文件**
   - 位置：`code\dist\BOSS直聘管理工具.exe`
   - 文件大小：约 30-50 MB

### 方法 2：手动打包

```cmd
# 1. 安装依赖
pip install -r requirements.txt

# 2. 安装 PyInstaller
pip install pyinstaller

# 3. 执行打包
pyinstaller web_app.spec

# 4. 生成的文件在 dist 目录
```

## 二、使用说明

### 运行 exe 文件

1. **双击运行**
   - 双击 `BOSS直聘管理工具.exe`
   - 会自动打开一个控制台窗口

2. **查看启动信息**
   ```
   ============================================================
   BOSS 直聘 Web 管理界面
   ============================================================

   启动服务器...
   数据库路径: C:\xxx\data\boss_jobs.db

   访问地址: http://localhost:5001

   按 Ctrl+C 停止服务器
   ============================================================
   ```

3. **打开浏览器**
   - 在浏览器中访问：`http://localhost:5001`
   - 开始使用工具

4. **停止服务**
   - 在控制台窗口按 `Ctrl + C`
   - 或直接关闭控制台窗口

## 五、常见问题

### Q1: 杀毒软件报警？
**A**: PyInstaller 打包的程序可能被误报。可以：
- 添加到杀毒软件白名单
- 或使用"允许运行"选项

### Q2: 端口 5001 被占用？
**A**: 修改 `web_app.py` 最后一行的端口号：
```python
app.run(debug=True, host='127.0.0.1', port=5002)  # 改为 5002
```
然后重新打包。

### Q3: 如何更新程序？
**A**:
1. 保留 `data/boss_jobs.db` 数据库文件
2. 删除旧的 exe
3. 放入新的 exe
4. 数据会继续使用

### Q4: 数据库在哪里？
**A**:
- 数据库文件：`data/boss_jobs.db`
- 位于 exe 文件的同级目录
- 首次运行时自动创建

### Q5: 可以更改端口吗？
**A**: 可以。修改 `web_app.py` 的端口后重新打包。

## 六、高级配置

### 隐藏控制台窗口

如果不想显示控制台窗口，修改 `web_app.spec`：

```python
exe = EXE(
    ...
    console=False,  # 改为 False
    ...
)
```

重新打包后，程序会在后台运行，不显示控制台。

### 添加自定义图标

1. 准备一个 `.ico` 格式的图标文件
2. 修改 `web_app.spec`：
   ```python
   icon='path/to/your/icon.ico',  # 添加图标路径
   ```
3. 重新打包

### 单文件打包

如果想打包成单个 exe 文件（启动会稍慢）：

```python
exe = EXE(
    ...
    onefile=True,  # 添加此行
    ...
)
```
