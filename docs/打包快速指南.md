# Windows EXE 打包 - 快速指南

## 📦 打包文件清单

### 核心文件
```
code/
├── web_app.py           # 主程序（已修改支持打包）
├── database.py          # 数据库模块（已修改支持打包）
├── web_app.spec         # PyInstaller 配置文件 ✨
├── requirements.txt     # 依赖列表（已添加 PyInstaller）
├── build.bat            # Windows 自动打包脚本 ✨
├── build.py             # 跨平台打包脚本 ✨
├── build.sh             # macOS/Linux 打包脚本 ✨
├── 用户使用说明.txt      # 用户手册 ✨

    ├── base.html
    ├── paste.html
    ├── jobs.html
    └── companies.html
```

## 🚀 Windows 打包步骤

### 方法 1：双击运行（最简单）
```
1. 进入 code 目录
2. 双击 build.bat
3. 等待完成
4. 获取 dist/BOSS直聘管理工具.exe
```

### 方法 2：命令行
```cmd
cd code
python build.py
```

## 📋 代码修改说明

### 1. web_app.py
```python
# 添加打包支持
if getattr(sys, 'frozen', False):
    # 打包后的 exe 环境
    BASE_DIR = Path(sys.executable).parent
else:
    # 开发环境
    BASE_DIR = Path(__file__).parent.parent
```

### 2. database.py
```python
# 同样的打包支持逻辑
if getattr(sys, 'frozen', False):
    base_dir = Path(sys.executable).parent
else:
    base_dir = Path(__file__).parent.parent
```

## ⚙️ PyInstaller 配置

### web_app.spec 关键配置
```python
# 包含模板文件
datas=[
    (str(base_dir / 'code' / 'templates'), 'templates'),
],

# 隐藏导入
hiddenimports=[
    'bs4',
    'lxml',
    'sqlite3',
],

# 控制台模式
console=True,  # 显示控制台窗口
```

## 🐛 常见问题

### Q: 打包失败？
A: 确保 PyInstaller 版本 ≥ 6.0
```cmd
pip install --upgrade pyinstaller
```

### Q: 运行时报错找不到模块？
A: 在 web_app.spec 的 hiddenimports 中添加

### Q: 模板文件找不到？
A: 检查 web_app.spec 的 datas 配置

### Q: 数据库路径错误？
A: 确认 web_app.py 和 database.py 的打包支持代码
