## 🚀 快速使用

### 方式一：提取数据 + 保存到数据库（推荐）

#### 1. 手动收集 HTML 文件

在浏览器中打开 BOSS 直聘，登录后搜索以下行业，将每个搜索结果页面保存为 HTML：
- 智能制造
- 机器人
- 医疗器械
- 新能源
- 芯片
- 光伏

保存到 `data/collected/` 目录，文件命名格式：`{行业名称}.html`

#### 2. 提取数据并保存到数据库

```bash
python3 code/extract_jobs_v6.py
```

这个脚本会：
- 从 HTML 文件中提取岗位信息
- 去重数据
- **自动插入到 SQLite 数据库**（data/boss_jobs.db）
- 生成 Excel 报告到 `reports/` 目录
- 显示统计信息

#### 3. 查询数据库

```bash
python3 code/query_database.py
```

提供交互式查询界面：
- 查看总体统计
- 按来源统计
- 查看岗位最多的企业
- 搜索岗位
- 查看所有企业
- 导出数据为 JSON

---

### 方式二：导入历史 Excel 数据

如果已有 Excel 报告，可以导入数据库：

```bash
python3 code/import_excel_to_db.py
```

会自动导入 `reports/` 目录下的所有 Excel 文件。

---

### 方式三：半自动化引导

```bash
python3 code/collect_jobs_manual.py
```

按照提示手动收集数据，然后自动提取。

## 🎯 企业监测功能

### 监测时间范围

企业监测任务支持时间范围限制功能，允许用户设置监测任务只在特定时间段内执行。

#### 功能特性

- **时间精度**: 精确到分钟（如 10:00-17:30）
- **默认时间范围**: 工作时间 09:00-18:00
- **时区支持**: 统一使用北京时间（Asia/Shanghai）
- **跨天限制**: 不支持跨天时间范围（开始时间必须小于结束时间）
- **可选配置**: 不设置时间范围则全天 24 小时执行

#### 执行行为

- **在时间范围内**: 按设定的间隔正常执行监测任务
- **在时间范围外**: 自动跳过执行，不调用 API，节省资源

#### 使用方法

**创建监测配置时设置时间范围:**

通过 Web 界面创建监测配置时，可以设置监测时间范围：

```
监测时间范围: 09:00 至 18:00
```

- 使用 HTML5 时间选择器，支持分钟级精度
- 前端会验证时间范围的有效性（不支持跨天）
- 可选字段，不设置则使用默认值 09:00-18:00

**更新现有配置的时间范围:**

通过配置管理界面可以随时更新监测时间范围：

1. 进入监测配置管理页面
2. 找到要修改的配置
3. 点击编辑按钮
4. 修改开始时间和结束时间
5. 保存后调度器会自动应用新的时间范围

**时间范围示例:**

- 工作时间: `09:00` - `18:00`
- 上午监测: `09:00` - `12:00`
- 下午监测: `14:00` - `18:00`
- 全天监测: 不设置时间范围（或设为 00:00-23:59）

#### 技术实现

- **数据库字段**: `monitoring_start_time` 和 `monitoring_end_time`（格式 HH:MM）
- **调度器检查**: 每次执行任务前检查当前时间是否在范围内
- **日志记录**: 跳过执行时记录时间范围信息（带北京时区标识）
- **API 验证**: 创建和更新配置时验证时间格式和范围有效性
