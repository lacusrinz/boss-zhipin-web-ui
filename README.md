## 🚀 快速使用

### 方式一：提取数据 + 保存到数据库（推荐）

#### 1. 手动收集 HTML 文件

在浏览器中打开 BOSS 直聘，登录后搜索以下行业，将每个搜索结果页面保存为 HTML：
- 智能制造
- 机器人
- 医疗器械
- 新能源
- 芯片
- 光伏

保存到 `data/collected/` 目录，文件命名格式：`{行业名称}.html`

#### 2. 提取数据并保存到数据库

```bash
python3 code/extract_jobs_v6.py
```

这个脚本会：
- 从 HTML 文件中提取岗位信息
- 去重数据
- **自动插入到 SQLite 数据库**（data/boss_jobs.db）
- 生成 Excel 报告到 `reports/` 目录
- 显示统计信息

#### 3. 查询数据库

```bash
python3 code/query_database.py
```

提供交互式查询界面：
- 查看总体统计
- 按来源统计
- 查看岗位最多的企业
- 搜索岗位
- 查看所有企业
- 导出数据为 JSON

---

### 方式二：导入历史 Excel 数据

如果已有 Excel 报告，可以导入数据库：

```bash
python3 code/import_excel_to_db.py
```

会自动导入 `reports/` 目录下的所有 Excel 文件。

---

### 方式三：半自动化引导

```bash
python3 code/collect_jobs_manual.py
```

按照提示手动收集数据，然后自动提取。

## 🎯 企业监测功能

### 多 Token 套餐管理

企业监测模块支持配置多个 RiskBird API Token 套餐，每个套餐包含备注名称、Token 和 App UUID。可在监测配置中指定使用哪个套餐。

#### 功能特性

- **多套餐管理**: 添加、编辑、删除、测试多个 Token 套餐
- **按配置指定**: 每个监测配置可选择使用不同的 Token 套餐
- **向后兼容**: 未选择套餐时回退到旧的单 Token 配置
- **安全存储**: Token 使用 Fernet 加密存储，UI 仅显示脱敏值

#### 使用方法

**添加 Token 套餐:**

1. 进入监测页面，点击「Token 配置」按钮
2. 点击「+ 添加 Token 套餐」
3. 填写备注名称、Token、App UUID
4. 点击「保存」，可通过「测试」按钮验证连通性

**在监测配置中使用:**

1. 创建或编辑监测配置
2. 在「Token 套餐」下拉框中选择要使用的套餐
3. 选择「默认（旧配置）」可回退到旧的单 Token 模式

### 监测时间范围

企业监测任务支持时间范围限制功能，允许用户设置监测任务只在特定时间段内执行。

#### 功能特性

- **时间精度**: 精确到分钟（如 10:00-17:30）
- **默认时间范围**: 工作时间 09:00-18:00
- **时区支持**: 统一使用北京时间（Asia/Shanghai）
- **跨天限制**: 不支持跨天时间范围（开始时间必须小于结束时间）
- **可选配置**: 不设置时间范围则全天 24 小时执行

#### 执行行为

- **在时间范围内**: 按设定的间隔正常执行监测任务
- **在时间范围外**: 自动跳过执行，不调用 API，节省资源

#### 使用方法

**创建监测配置时设置时间范围:**

通过 Web 界面创建监测配置时，可以设置监测时间范围：

```
监测时间范围: 09:00 至 18:00
```

- 使用 HTML5 时间选择器，支持分钟级精度
- 前端会验证时间范围的有效性（不支持跨天）
- 可选字段，不设置则使用默认值 09:00-18:00

**更新现有配置的时间范围:**

通过配置管理界面可以随时更新监测时间范围：

1. 进入监测配置管理页面
2. 找到要修改的配置
3. 点击编辑按钮
4. 修改开始时间和结束时间
5. 保存后调度器会自动应用新的时间范围

**时间范围示例:**

- 工作时间: `09:00` - `18:00`
- 上午监测: `09:00` - `12:00`
- 下午监测: `14:00` - `18:00`
- 全天监测: 不设置时间范围（或设为 00:00-23:59）

#### 技术实现

- **数据库字段**: `monitoring_start_time` 和 `monitoring_end_time`（格式 HH:MM）
- **调度器检查**: 每次执行任务前检查当前时间是否在范围内
- **日志记录**: 跳过执行时记录时间范围信息（带北京时区标识）
- **API 验证**: 创建和更新配置时验证时间格式和范围有效性

### 监测日期筛选

执行记录和监测结果支持日期范围筛选功能：

#### 功能特性

- **日期精度**: 精确到天
- **默认日期**: 默认选中当天日期
- **跨天范围**: 支持跨天范围筛选
- **可选功能**: 不筛选显示全部数据
- **灵活查询**: 支持单日或多日范围查询

#### 使用方法

**筛选执行记录:**

1. 进入监测管理页面
2. 在执行记录表格上方找到日期选择器
3. 选择开始日期和结束日期
4. 点击"筛选"按钮应用筛选
5. 点击"重置"按钮清除筛选，显示全部记录

**筛选监测结果:**

1. 进入监测管理页面
2. 在监测结果表格上方找到日期选择器
3. 选择开始日期和结束日期
4. 点击"筛选"按钮应用筛选
5. 点击"重置"按钮清除筛选，显示全部结果

#### 日期验证

- **正常范围**: 开始日期 ≤ 结束日期
- **错误提示**: 结束日期早于开始日期时显示错误提示
- **智能提示**: 前端实时验证，防止无效查询

#### API 兼容性

- **无参数**: 不传日期参数，返回全部数据
- **单日期**: 传单个日期参数，筛选当天数据
- **日期范围**: 传完整日期范围，筛选范围内数据

### 监测结果配置名

监测结果表格新增配置名列，显示监测配置的名称：

#### 功能特性

- **位置**: 表格最后一列
- **内容**: 显示配置名称
- **已删除配置**: 显示"已删除"（灰色文本）
- **实时更新**: 从 monitoring_configs 表获取最新配置名

#### 显示规则

- **正常配置**: 显示配置的实际名称
- **已删除配置**: 显示"已删除"文本，使用灰色样式
- **配置关联**: 通过 config_id 字段关联配置信息
- **数据处理**: 后端 API 自动处理已删除配置

#### 技术实现

- **数据库关联**: monitoring_results.config_id → monitoring_configs.id
- **LEFT JOIN**: 使用左连接确保所有结果都能显示
- **动态查询**: 根据配置是否存在动态显示配置名或"已删除"
- **前端样式**: 已删除配置使用 Bootstrap text-muted 类

### 飞书消息推送

企业监测模块支持自动推送通知到飞书。

#### 功能特性

- **自动触发**: 当监测到新企业时自动推送，未发现新企业时不推送
- **可配置**: 每个监测配置可独立设置是否启用推送
- **目标灵活**: 支持群聊和私聊（个人）
- **纯文本格式**: 消息简洁明了，包含企业名称、配置名称、发现时间等信息
- **非阻塞**: 推送失败不影响监测任务执行，错误会记录到日志

#### 配置方法

**1. 设置环境变量**

创建 `.env` 文件：

```bash
FEISHU_APP_ID=your_app_id
FEISHU_APP_SECRET=your_app_secret
```

**2. 创建监测配置时启用飞书推送**

- 在创建监测配置表单中，找到 "飞书消息推送（可选）" 部分
- 勾选 "启用飞书消息推送"
- 选择推送目标类型（群聊或私聊）
- 输入群聊 ID 或用户 open_id
- 点击 "发送测试消息" 验证配置正确

#### 如何获取群聊 ID / 用户 open_id

参考飞书官方文档: [如何获取群聊 ID 和用户 open_id](https://open.feishu.cn/document/ukTMukTMukTM/uUTNz4SN1MjL1UzM)

#### 消息格式示例

```
🔔 企业监测新发现

监测配置: 华东地区监测
发现时间: 2026-03-18 14:30
新增企业: 3 家

企业列表:
1. 上海智能制造有限公司 (注册资本: 500万)
2. 苏州医疗器械科技有限公司 (注册资本: 200万)
3. 无锡新能源技术股份有限公司 (注册资本: 1000万)
```

#### 推送日志

所有飞书推送记录都会保存到 `feishu_push_logs` 表中，包括:
- 推送时间
- 推送企业数量
- 成功/失败状态
- 错误信息（如果失败）
